# 🔍 GitHub User Finder

A sleek and modern web application built with **React.js** that allows users to search for GitHub profiles seamlessly, view detailed user statistics, repositories, follower counts, and direct links to their GitHub accounts.

---

## 🚀 Features

* **User Search:** Search any valid GitHub username instantly by entering the name and clicking search.
* **Profile Card Component:** Displays user avatar, full name, username, bio, public repositories count, and followers count in a clean card layout.
* **Error Handling:** Gracefully handles invalid usernames and API limits with user-friendly error messages.
* **Modular CSS Styling:** Built using separate, clean CSS files (`Searchbar.css` and `ProfileCard.css`) following best component-driven development practices.
* **Responsive Design:** Fully responsive layout optimized for all screen sizes.

---

## 🛠️ Tech Stack

* **Frontend Library:** React.js (Functional Components, Hooks like `useState`)
* **Styling:** Modular CSS (Vanilla CSS with structured classes)
* **API Integration:** GitHub REST API (`https://api.github.com/users/:username`)
* **Build Tool:** Vite
